## Prototype findings

### typecheck=True
- Universality held: all eight providers (raw LLM, pure tool, MCP-shaped server, harness agent, graph strategy, remote A2A, human, OpenAI-compat local model) run through one invoke() path with zero capability-identity branching — enforced by construction (table dispatch over closed protocol discriminants) and by validate.sh's grep gate, which also forbids the kernel from ever naming a capability in a string literal.
- Spine gap found — tier ordering must be manifest data: the kernel can only evaluate 'reasoning >= trace' if the tiered axis carries its own ordered ladder in the manifest; otherwise the kernel would need axis semantics, violating the core rule. The spine's 'axis-typed, tiered' grammar (§4) implies but never states this; it should be explicit in doc 06.
- Spine gap found — budget-exceeded as an interrupted (resumable) state conflicts with sealed, decrement-only Grants: there is no spine mechanism to refill authority. The prototype added a re-grant verb (resume(id, payload, {grantId}) swapping the invocation's effective grant), which quietly breaks the Binding's 'sealed grant' property; the design needs an explicit re-grant/top-up story.
- Spine tension found — checkpoint cut vs journal-replay-to-tip: replaying the JSONL rebuilds state PAST the checkpoint, so restore() can only validate the snapshot against replayed state, not rewind. The spine names fork-from-checkpoint as the primary repair verb but says nothing about reconciling a checkpoint with a longer journal; a real kernel needs fork lineage here. Restore was made load-bearing anyway: replayed cells are inert until restore() re-arms them, and resume-before-restore is refused.
- Suspension needed an 'origin' discriminator (provider | policy | kernel) the spine doesn't have: policy-stage suspensions occur before the provider ever runs and resume by continuing the sealed policy route from a stored index (never re-running earlier stages), while provider suspensions resume by re-entering the provider with ctx.resume. One undifferentiated suspension notion does not implement cleanly.
- Grants-as-lineage worked better than expected: charging a child grant atomically decrements every ancestor at the same commit point, so delegated spend (coding agent's attenuated child) is visible on the root budget for free, and attenuation checks against parent REMAINING (not initial) budgets compose correctly. Cell reentrancy is the open question the spine is silent on: child invocations must run in fresh cells or the single-writer queue deadlocks.
